# Технический план реализации

| Этап | Результат | Критерий готовности | Риски |
|---|---|---|---|
| 1. Аудит материалов | AUDIT и перечень источников | У каждого исходного файла есть назначение и статус | Утверждённое смешано с черновиком |
| 2. Registry | YAML-реестры и правила идентификаторов | Факт, допущение и решение различимы | Дублирование с Docs |
| 3. Структура документов | Утверждённые шаблоны разделов | Нет финансовых чисел без источника | Преждевременная фиксация содержания |
| 4. Google-папка | Выделенная `Колобочная / Investment` | Корневой folder ID записан только локально | Ошибка прав или неверная папка |
| 5. OAuth | Локальная авторизация с минимальными scopes | Токен не попадает в Git | Избыточные разрешения |
| 6. Тестовый документ | Непроизводственный Google Doc | Создан внутри allowlist-папки | Случайное изменение боевых материалов |
| 7. Чтение документа | Нормализованный snapshot | Контент, revision и комментарии зафиксированы | Потеря ручной разметки |
| 8. Preview изменений | План операций и читаемый diff | Ничего внешнего не изменено | Неполный diff структур Docs |
| 9. batchUpdate | Контролируемое применение | Есть decision ID, revision check и журнал | Конфликт параллельных правок |
| 10. Google Sheets | Каркас модели с формулами | Формулы сохранены, значения имеют источник/assumption | Подмена формул числами |
| 11. Согласованность | validate-отчёт | Нет сиротских источников, конфликтов статуса и несогласованных чисел | Ложноположительные проверки |
| 12. MCP-интерфейс | Инструменты read/preview/apply/validate/rollback | Apply требует явного подтверждения | Слишком широкие команды |
| 13. Управление через ChatGPT | Управляемый workflow через MCP | Агент не обходит preview и policy | Непрозрачное действие модели |
| 14. Backup и rollback | Snapshot и журнал rollback | Возможен откат конкретной операции | Неполный rollback Docs API |

Каждый этап после 1 требует отдельного decision ID перед внешним изменением.
