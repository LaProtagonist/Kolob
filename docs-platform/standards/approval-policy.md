# Политика согласования

Статусы: `idea` → `research` → `proposed` → `approved`; также `superseded` и `rejected`.

- `idea`: не доказано, может быть отброшено.
- `research`: есть источник для изучения, но нет решения.
- `proposed`: готово к рассмотрению; не публиковать как факт.
- `approved`: можно использовать в целевых документах в пределах решения.
- `superseded`: заменено решением с указанной связью.
- `rejected`: не использовать.

Для изменения создать decision record с ID, датой, владельцем, затронутыми документами, источниками и статусом. Утверждённый текст меняется только решением, а связанный набор документов обновляется одной согласованной серией.
