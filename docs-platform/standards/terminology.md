# Терминология «Колобочной»

| Термин | Нормативная формулировка | Статус / комментарий |
|---|---|---|
| Название | «Колобочная» | approved; «Колобовщина» не использовать. |
| Базовая категория | «еда в пути» | approved; «стрит-фуд» не использовать как основное определение. |
| Главная формула | «Колобочная — еда в пути. Всё внутри» | approved. |
| Формула продукта | «Колобок — форма, объединяющая качество, удобство и разнообразие» | approved. |
| Качество | «Быстрая еда не должна быть компромиссом к качеству» | approved; не заменять медицинскими или диетологическими заявлениями. |
| Категории | мясные, морские, вегетарианские, сладкие | approved как структура ассортимента; не выводить состав и характеристики без источника. |
| Растительные ингредиенты | часть растительных ингредиентов выращивается самостоятельно | approved; конкретные объёмы, культуры и площадки — только с источником. |
| Первая будущая точка | рассматривается как пилотный актив сети | proposed; это не утверждение о покупке конкретного объекта. |
| Недвижимость | сравнивать покупку, аренду и долгосрочную аренду с возможностью субаренды | proposed; решение о конкретном помещении не утверждено. |

Допустимое контекстное сравнение: «быстрая еда» или «фастфуд» только при пояснении, что «Колобочная» позиционируется как «еда в пути». Не использовать «Колобовщина», «полезный фастфуд», гарантии качества или финансовые обещания.
