# Стандарт финансовой модели

- Единственное место расчётов — Google Sheets; Docs содержат только согласованные выводы и ссылки на Sheet/версию.
- Каждая входная цифра имеет ID, единицу, период, источник, владельца и `source` либо `assumption`.
- Формулы остаются формулами; статические числа не подменяют вычисления.
- Сценарии и чувствительность имеют именованные вкладки и не смешиваются с базовой моделью.
- На текущем этапе реестр метрик пуст: финансовые показатели не создаются и не предполагаются.
- Перед публикацией обязателен validate: ссылки, единицы, отсутствие пустых источников и согласованность с registry.
