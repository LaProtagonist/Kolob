# Стиль документов

- Язык — русский; название проекта: «Колобочная».
- Документ начинаетcя с цели, статуса, владельца, decision ID и списка источников.
- Факты, допущения и вопросы маркируются явно; финансовые таблицы не вставляются в Docs как скриншоты.
- Для цифр указывать единицу, период, источник, дату проверки и статус.
- Не обещать доходность и не использовать неподтверждённые claims.
- Сохранять короткие заголовки, одну мысль на раздел и нейтральный партнёрский тон.
