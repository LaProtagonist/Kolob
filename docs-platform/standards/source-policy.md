# Политика источников

Приоритет: первичный документ/подтверждение → утверждённый текст → опубликованный код сайта → аналитический материал → гипотеза.

Каждый источник получает ID в `registry/sources.yaml`, тип, путь/URL, дату проверки и оценку надёжности. Google Docs и Sheets регистрируются по стабильному ID, но их содержание снапшотится в журнал до изменения. Референсы конкурентов не доказывают факты о «Колобочной».
